IOT_REMOTE_CONTROLLER

這是一個基於 Flask 架構的 全方位遠端控制系統。 它成功橋接了 Web 介面與 Windows 系統底層，讓使用者能透過手機瀏覽器或 LINE Bot 即時操控電腦。

⚡ 核心整合技術：

  • 硬體層控制 (PyAutoGUI)： 實作虛擬觸控板，透過 WebSocket/SocketIO 傳輸座標，達成低延遲的遠端滑鼠與視窗管理 (Alt+F4)。
  • 自動化與爬蟲： 整合 Selenium 自動喚醒 ChatGPT 並自動輸入內容，同時結合 BeautifulSoup 抓取 CNA 即時新聞並推送至 LINE。

AGENT_SQL_CORE

這是一個讓資料庫「聽懂人話」的智慧代理人。使用者無需撰寫複雜代碼，只需透過 日常自然語言 即可直觀地進行數據的 檢索、分析 與 編輯。

🛡️ 安全與效能優化：

  • 數據去識別化 (Sanitization)： 透過 DataVault 雜湊技術，在傳輸過程中遮蔽敏感個資，確保操作時真實數據絕不外洩至外部 API。
  • 遞迴式自我修復： 系統具備自動除錯機制，能即時修正 SQL 語法偏差，保證零門檻操作下的數據準確性。

GESTURE_CONTROLLED_GAME

結合 電腦視覺 (Computer Vision) 與經典遊戲的創新專案。 系統即時捕捉攝影機影像，透過 MediaPipe 推論出 21 個手部關鍵點，並利用 向量幾何 計算手指彎曲角度，實現無接觸的遊戲體驗。

📐 核心演算法 (Vector Math)：

為了精準判斷手指是「伸直」還是「彎曲」，程式計算指節向量之間的夾角。
公式：Angle = acos( (v1⋅v2) / (|v1|*|v2|) )

🖐️

Gesture: HIGH FIVE

所有手指角度 < 50°（伸直）

ACTION: JUMP (跳躍)
🤟

Gesture: SPIDER-MAN

特定手指彎曲（≥ 50°）

ACTION: DUCK (蹲下)
