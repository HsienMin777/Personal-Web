REMOTE_CONTROLLER

結合 WebSocket 即時通訊與系統自動化腳本，打造專屬的 跨裝置遠端遙控中心。A cross-device remote control hub built by combining real-time WebSocket communication with system automation scripts.

🌟 核心亮點與實作細節：Core Highlights & Implementation Details:

  • 跨端效能調優（Performance Tuning）： 利用 Flask-SocketIO 建立雙向連線，將手機螢幕轉化為電腦觸控板。開發過程中發現高頻率觸控事件會導致作業系統游標卡頓，經排查後實施雙向優化：前端導入 requestAnimationFrame 進行事件節流，後端關閉 pyautogui 的預設強制延遲 (PAUSE=0)，最終達成絲滑的操控體驗。
  • Cross-Device Performance Tuning: Built a bidirectional connection with Flask-SocketIO to turn a phone screen into a computer trackpad. High-frequency touch events were found to cause OS cursor lag, fixed with a two-sided optimization: the frontend throttles events with requestAnimationFrame, while the backend disables pyautogui's default forced delay (PAUSE=0), achieving a silky-smooth control experience.
  • 遠端系統自動化（System Automation Dashboard）： 建置基於 HTTP 的多元控制面板，整合 PyAutoGUI 實作 OS 層級的按鍵與視窗控制。功能涵蓋遠端批次關閉應用程式視窗 (Alt+F4)、一鍵開啟特定網頁，以及透過模擬鍵盤操作自動開啟 ChatGPT 網頁並貼上提問內容。
  • Remote System Automation Dashboard: Built a multi-function HTTP-based control panel integrating PyAutoGUI for OS-level key and window control. Features include remotely batch-closing application windows (Alt+F4), one-click opening of specific web pages, and simulating keystrokes to auto-open ChatGPT and paste in a query.
  • LINE Bot 第三方串接（Instant Notification）： 串接 LINE Message API，並嚴格落實環境變數 (.env) 資安控管。當伺服器啟動時，系統會主動推播控制台專屬網址至手機；同時結合 Web Scraping 技術，支援一鍵爬取即時新聞並透過 LINE 傳送，打造完整的跨平台互動。
  • LINE Bot Third-Party Integration (Instant Notification): Integrated the LINE Message API with strict environment-variable (.env) security controls. On server startup, the system proactively pushes the console's dedicated URL to the phone; it also supports one-click scraping of live news that's delivered over LINE, rounding out a complete cross-platform interaction.

AGENT_SQL_CORE

這是一個具備 自我修正機制 (Self-Correction) 與 資料遮蔽 (Data Masking) 功能的 Text-to-SQL 實作。使用者無需撰寫複雜代碼，只需透過日常自然語言即可直觀地進行數據的檢索、分析與編輯。A Text-to-SQL implementation featuring self-correction and data masking. Users can intuitively retrieve, analyze, and edit data using everyday natural language, with no need to write complex code.

🛠️ 專案重點與實作細節：Project Highlights & Implementation Details:

  • 自動除錯與重試機制（Self-Correction Loop）： 為了解決 LLM 生成 SQL 經常發生幻覺或欄位對不上的問題，實作了自動重試的邏輯。當生成的 SQL 執行報錯時，程式會攔截 Error Message 並結合當前的 Schema 結構，將錯誤資訊回傳給 LLM 重新修正，直到語法能順利執行為止。
  • Self-Correction Loop: To fix LLM-generated SQL frequently hallucinating or mismatching column names, an automatic retry loop was implemented. When generated SQL throws an execution error, the program intercepts the error message, combines it with the current schema, and feeds it back to the LLM to correct until the query executes cleanly.
  • 敏感資料遮蔽中介層（Data Vault Middleware）： 為了避免將使用者的真實 PII（如姓名、Email 等）明文傳送給外部 LLM API，實作了中介層機制。在發送 Prompt 前先將敏感字串抽換為 Token（如 [SECRET_VALUE_0]）；待 SQL 生成後，再於本地端還原為真實資料寫入資料庫，降低資料外洩風險。
  • Data Vault Middleware: To avoid sending users' real PII (names, emails, etc.) in plaintext to an external LLM API, a middleware layer swaps sensitive strings for tokens (e.g. [SECRET_VALUE_0]) before the prompt is sent; after SQL is generated, the tokens are restored to real data locally before writing to the database, reducing the risk of data leakage.
  • 讀寫分離的執行邏輯（Hybrid Executor）： 程式會自動解析 SQL 類型並對應不同操作：若是 SELECT 查詢，會將結果打包成 Pandas DataFrame 方便後續處理；若是 INSERT/UPDATE 等寫入操作，則自動執行 Transaction Commit 確保資料正確寫入。
  • Hybrid Executor (Read/Write Separation): The program automatically parses the SQL type and dispatches accordingly: SELECT queries are packaged into a Pandas DataFrame for downstream processing, while INSERT/UPDATE writes automatically trigger a transaction commit to ensure data is written correctly.
  • Prompt 結構化設計： 在 Prompt 中套用 Few-Shot Learning 與 Chain-of-Thought (CoT) 技巧，提供範例幫助 LLM 更好地理解關聯式資料庫結構，從而產出包含 JOIN 等較複雜的查詢語句。
  • Structured Prompt Design: Few-Shot Learning and Chain-of-Thought (CoT) techniques are applied within the prompt, providing examples that help the LLM better understand the relational schema and produce more complex queries, including JOINs.

SNAKE_MARL_DQN

基於 Pygame 與 PyTorch 打造的 多智能體強化學習 (MARL) 實驗環境，探討非對稱目標下的 AI 策略演化。A multi-agent reinforcement learning (MARL) sandbox built with Pygame and PyTorch, exploring AI strategy evolution under asymmetric objectives.

🌟 核心亮點與技術實現：Core Highlights & Technical Implementation:

  • 多智能體非對稱對抗（Asymmetric MARL）： 設計兩種截然不同的 AI 角色——採集者（Gatherer／藍蛇）目標是盡可能吃掉紅色食物以增加長度；獵人（Hunter／綠蛇）對食物免疫且無感，唯一目標是攔截、封鎖或擊殺採集者，藉由逼迫對手撞上自己的身體來獲取分數與成長。
  • Asymmetric Multi-Agent Adversarial Setup: Two fundamentally different AI roles were designed — the Gatherer (blue snake), whose goal is to eat as much red food as possible to grow longer, and the Hunter (green snake), which is immune and indifferent to food and whose sole objective is to intercept, block, or kill the Gatherer by forcing it to collide with its own body to earn score and length.
  • 深度 Q 網路架構（DQN Architecture）： 系統中包含兩個完全獨立的 AI 模型，各自擁有網路結構 3-layer MLP（15 → 256 → 128 → 3），以及穩定機制：容量達 20,000 筆的 Experience Replay Buffer，Target Network 每 1,000 步同步一次，搭配 Adam Optimizer（梯度裁剪截斷）確保模型收斂。
  • Deep Q-Network Architecture: The system contains two fully independent AI models, each with a 3-layer MLP (15 → 256 → 128 → 3), plus stabilization mechanisms: a 20,000-entry Experience Replay Buffer, a Target Network synced every 1,000 steps, and an Adam Optimizer with gradient clipping to ensure convergence.
  • 狀態空間與獎勵工程（State Space & Reward Shaping）： 賦予 AI 15 個特徵維度的感知能力，包含前方／左右障礙物判斷、自身方向、目標相對方位，以及對手的移動方向。透過精心調校的 Reward Function（例如獵人成功肉身封鎖對手給予 +200 激勵），有效解決稀疏獎勵問題。
  • State Space & Reward Shaping: Gives the AI 15 perception feature dimensions, including forward/left/right obstacle detection, its own direction, the target's relative position, and the opponent's movement direction. A carefully tuned reward function (e.g. +200 for the Hunter successfully blocking the opponent) effectively resolves the sparse-reward problem.
  • 容器化無頭訓練環境（Dockerized Headless Training）： 除了支援本機 Pygame 視覺化即時渲染外，也撰寫了 Dockerfile 與 docker-compose.yml，透過 SDL_VIDEODRIVER=dummy 實作無頭模式（Headless），方便在背景或雲端伺服器進行長時間的自動化對局訓練。
  • Dockerized Headless Training: Besides local real-time Pygame rendering, a Dockerfile and docker-compose.yml were written to implement headless mode via SDL_VIDEODRIVER=dummy, making long-running automated training convenient on background or cloud servers.

  • ● 感知：多了對手目前的移動方向，比採集者多一份資訊優勢。Perception: also senses the opponent's current movement direction, an informational edge over the Gatherer.

HAND_DINOSAUR

用手勢取代鍵盤！這是一款基於 MediaPipe 與 Pygame 開發的即時體感小恐龍遊戲。Ditch the keyboard for hand gestures! A real-time motion-controlled dino game built with MediaPipe and Pygame.

👁️ 電腦視覺與手部追蹤 (Computer Vision)：Computer Vision & Hand Tracking:

整合 OpenCV 處理即時視訊串流，並介接 Google MediaPipe Hands 模型，以低延遲準確捕捉手部的 21 個關鍵點。Integrates OpenCV for real-time video stream processing and interfaces with Google's MediaPipe Hands model to accurately capture 21 hand landmarks with low latency.

📐 基於向量運算的手勢分類器 (Gesture Recognition Logic)：Vector-Based Gesture Classifier (Gesture Recognition Logic):

有別於傳統的機器學習圖像分類，實作了幾何角度演算法：計算 5 根手指關節的彎曲角度，設定 50° 為伸直與捲縮的閾值，精準判斷「張開手掌（跳躍）」、「特定三指伸直（蹲下）」與「握拳（忽略）」等動作。
公式：Angle = acos( (v1⋅v2) / (|v1|*|v2|) )Instead of traditional ML-based image classification, a geometric angle algorithm was implemented: it computes the bend angle of each of the 5 finger joints and uses 50° as the threshold between extended and curled, precisely distinguishing "open palm (jump)", "three specific fingers extended (duck)", and "closed fist (ignore)".
Formula: Angle = acos( (v1⋅v2) / (|v1|*|v2|) )

🔗 非同步輸入與遊戲引擎整合 (System Integration)：Asynchronous Input & Game Engine Integration (System Integration):

實作了兩種整合架構以應對不同的軟體設計模式：Two integration architectures were implemented to handle different software design patterns:

  • 事件模擬驅動： 透過 keyboard 套件觸發 OS 層級的全域按鍵事件，讓手勢可以直接控制任何支援鍵盤的應用程式。
  • Simulated Event-Driven Input: Uses the keyboard package to trigger OS-level global key events, letting gestures directly control any application that accepts keyboard input.
  • 狀態直接注入： 繞過作業系統的按鍵佇列，將辨識結果直接傳入 Pygame 角色更新邏輯 Dinosaur.update()，提升遊戲反應速度與穩定性。
  • Direct State Injection: Bypasses the OS keystroke queue and feeds recognition results directly into the Pygame character update logic Dinosaur.update(), improving game responsiveness and stability.

OFFERDASH_AI_COACH

OfferDash 是一套 AI 驅動的一站式求職教練平台，從履歷健檢、模擬面試到面試復盤，全面追蹤使用者的求職進度。OfferDash is an AI-driven, all-in-one job-hunting coach platform that tracks a user's job search end to end — from resume health checks and mock interviews to post-interview reviews.

🌟 核心亮點與技術實現：Core Highlights & Technical Implementation:

  • 沉浸式 AI 模擬面試（Voice-Interactive AI Interview）： 摒棄純文字對話，整合 OpenAI TTS（onyx 音色）與瀏覽器原生 Web Speech API（並以 Whisper 作為備援），打造全語音的擬真面試戰場，可根據上傳的 PDF 履歷與 JD 動態生成客製化追問。
  • Immersive Voice-Interactive AI Interview: Ditching plain text chat, this integrates OpenAI TTS (onyx voice) with the browser's native Web Speech API (backed by Whisper as fallback) to build a fully voice-driven, realistic interview arena that dynamically generates customized follow-up questions based on the uploaded PDF resume and job description.
  • 履歷 × JD 雙向診斷系統（ATS Match & Diagnosis）： 運用 GPT-4o 分析履歷與職缺描述，產出 ATS 契合度分數，並嚴格要求 LLM 基於原文總結以避免幻覺，精準預測面試官意圖與必考題。
  • Resume × JD Bidirectional Diagnosis System (ATS Match & Diagnosis): Uses GPT-4o to analyze the resume against the job description, producing an ATS match score. The LLM is strictly constrained to summarize based on the source text to avoid hallucination, accurately predicting interviewer intent and likely questions.
  • 遊戲化復盤與成長機制（Gamified Feedback System）： 面試後自動生成復盤報告，抓出「最弱的 3 個回答」轉化為「翻盤任務」，依據產業別給予重答策略，引導使用者針對弱點刻意練習。
  • Gamified Feedback & Growth System: Automatically generates a post-interview review report, identifying the "3 weakest answers" and turning them into "comeback missions" with industry-specific re-answer strategies, guiding users toward deliberate practice on their weak points.
  • 非同步面試管家（Asynchronous Interview Calendar）： 內建行事曆系統，面試前 2 小時自動寄送含 AI 激勵語錄的提醒信。為避免寄信當下呼叫 LLM 造成超時失敗，信件內容在建立行程當下即非同步預先生成並存入 Supabase，確保 APScheduler 背景排程能穩定準時觸發寄送。
  • Asynchronous Interview Calendar: A built-in calendar system automatically sends a reminder email with an AI-generated motivational quote 2 hours before an interview. To avoid a timeout from calling the LLM at send time, email content is pre-generated asynchronously when the event is created and stored in Supabase, ensuring APScheduler's background job fires reliably and on time.
